# 原生学术逐页编排

用于新建原生学术正文页；默认模板、入口确认、20／18／16 pt 层级与
28 pt 页眉、14 pt 图题、几何和分页沿用
[默认学术模板方法](default-academic-template.md)。本文件说明怎样从论文
证据生成正文构图，不改用户已确认的主题色、主题图或功能页。

## 从证据到页面

1. **先做可用证据清单。** 阅读主论文的正文、图题、方法、附录与参考文献，
   将可用原图面板、表格、数据、公式与方法操作登记到既有 `source_map`／
   来源清单，记录图号、页码、变量、单位、对照、样本层级和误差定义。
   来源范围未定时先记录待确认；不要自动写 `supplied_only` 或擅自补文献。
   获授权后才沿相关研究补背景／前沿与讨论证据。
   PDF 原图优先依照[工具提取方法](scientific-figure-extraction.md)，用机器识别
   的区域及元数据提取，不以聊天模型目测坐标裁图为默认步骤。
2. **安排整场论证。** 默认面向有专业基础的听众，依次建立背景、相关研究／
   前沿、问题与缺口、方法、结果、比较讨论、综合判断。每一阶段分配到实际
   证据，不把论文目录逐项搬成页题。已有主张缺乏支持时缩小主张或保留问题，
   不靠泛化句填满。综合判断说明已有证据共同支持到哪里、何处仍待检验。
3. **先写逐页合同，再排版。** 新创作使用
   `authoring_contract: "academic_native.v1"`。在每个正文页保留既有字段，
   增加 `page_brief`；不要另造一套重复结论字段：

   | 字段 | 要写的内容 |
   | --- | --- |
   | `page_brief.question` | 一个该页能推进的科学问题；不能只写“介绍方法” |
   | `action_title` / `claim` | 可见判断与其精确定义；限定对象、尺度和证据强度 |
   | `evidence_sources` | 指向已登记来源及具体定位；不能仅写“论文原图” |
   | `page_brief.visual_rationale` | 图中哪些变量／关系支撑主张，正文还要补什么 |
   | `page_brief.information_gain` | 相比前页新增的证据、比较、机制、边界或推论 |
   | `speaker_note` | 长解释、推导、来源定位、限制与讲者推断的身份 |

4. **用已选模板校验编排。** 先看模板注册的布局、插槽和容量，再按证据关系
   选结构。`academic_general` 正文可用
   `layout_id: "scientific_composition"`。先确定听众需要追踪来源、理解模型、
   阅读原图、比较数值还是查具体条目。设置 `composition.kind: "auto"`，
   按[阅读任务表](scientific-composition.md#choose-by-reading-task)填写 `reading_task`
   和实际证据。生成器选择具体组合与图文位置，渲染记录保留选用结果。已有
   明确版式的页面可以继续使用具体类型。
   其他模板按各自的版式与组件合同编排，并保留同样的主张和证据来源检查。
   字段、实际 payload 与渲染／验收命令见
   [科学正文组合接口](scientific-composition.md)。
5. **用整套缩略图检查正文节奏。** 对照相邻几页的主视觉、图文比例和阅读
   路径。发现多处「短文＋表格」时，保留需要逐项查读精确值或条件的表格，
   在共用量尺上用条形表示大小、用排序点图突出名次、用配对点图表示同一
   类别的观测与估计。空间分布用原图，数据来源或方法输入输出用分层示意或
   证据组合。只换表头颜色不算换构图。需要逐页直接比较时，可以
   保留共同尺度和对齐。表格优先用 `evidence_matrix`，并在 PowerPoint 中
   确认可直接选中、编辑单元格。
6. **处理偏空的图文页。** 先放大主证据图并保留完整轴、图注和图例，再利用
   可用正文区组织有来源的解释。例如数据覆盖页可在原图旁区分各数据源提供
   的信息、整合后的样本数量与统计单位。证据有限时保留留白或和兼容页合并。
   检查图题、脚注和页码，并删去重复结论和仅占空间的装饰。

### 成稿审阅：信息增益与视觉层次

对照每页实际渲染，分别回答：原图或数据编码了什么，旁边的文字补充了
什么条件、比较或局限，以及听众是否能辨认该关系。页题、提示句、正文和
图题若反复表达同一事实，应合并或改写。不要用增加字数、无比较价值的
简单表格、重复统计数字或装饰图填满空白；证据不足时精简或合并页面。

原图应先保证坐标、图例及主要比较可读，必要时将相关面板放大并保留共享
图例。比较可比数值时，考虑 `paired_comparison`、条形图或原始图而不是
默认制表。并列不同统计口径时分别标注量尺、单位与分母，不能放在同一
数轴。数字、图题和简短解释各承担不同任务，以字号、字重、颜色与位置
形成明确层次。多页复用同一图文结构或表格时，结合证据关系重新排版。

自动结构检查通过只说明已声明的字段和规则通过，`adequate_pages` 不是
视觉质量或科学信息增益的评定。最终必须查看所有实际 PPTX 渲染，记录
并修复可读性、视觉节奏、图表含义和页码问题。不能声称结构检查已经
证明内容充分或美观。

## 六种编排配方

下列配方从问题选择，图形数量与占比按材料决定。图内原有轴、单位、图例、
对照和误差语义须保留；没有真实数值时只能画明确标注的结构示意。

| 适用问题与常用类型 | 图形怎样组织 | 正文增加什么 |
| --- | --- | --- |
| **共识为何仍留下缺口？** `figure_analysis` | 用已许可的主导原图或有来源的概念关系图呈现共识；开放侧栏区分已知条件与未覆盖条件，必要时将相应条件连接到图中对象。 | 指出主研究要补的对象、尺度或识别问题。提示句提出张力，正文具体界定缺口，不复述图的每条曲线。 |
| **证据覆盖到哪里？** `evidence_atlas` | 上部画论文—研究—估计等真实嵌套层级，下部排地图、样本分布或数据覆盖面板；图例与对应图严格对齐。不同单位分别标注，不能合并成一个 N。 | 纳入条件、覆盖盲区与可外推范围；不把检索记录、采样位置和独立研究当成相同样本单位。 |
| **输入如何变成可检验输出？** `method_diagram` | 把真实输入画成样本／变量／数据结构，经原文模型或变换连接到估计、预测或排名；有不同问题时分支，有验证时画清训练／检验、重采样或对照关系。 | 模型假设、独立单位、分支目的与验证标准。节点必须表达实际对象或操作；三段摘要加箭头、无来源的树／网络不合格。 |
| **两个结果能在什么条件下比较？** `figure_comparison` | 原图面板并排或上下开放排列，比较边界与文字基线对齐；可统一的量尺、变量和图例保持一致。量尺不相容时显式分开，并原生标出换算关系或条件。 | 共同条件、差异、分母／误差定义与敏感性。不能把排名、回归系数与效应量放到同一数轴上。 |
| **哪项证据支撑哪一级判断？** `evidence_matrix` | 研究或设计类型为列，估计对象、控制方式、尺度和外推条件为行，使用可编辑比较表；有用时附原图条带，已有图不足也可用有来源的表格独立表达。 | 明确哪些结果可比、哪些差异可能来自设计，最后给条件化判断。表格格线承载比较关系，不用多张装饰卡片代替。 |
| **量尺、机制或识别改变后判断稳不稳？** `figure_analysis` 或 `figure_comparison` | 主证据与替代量尺、模型关系或验证结果共同呈现；必要时用原生公式连接输入范围与输出。可采用跨栏推导加原图、上下证据链，避免再复制前页的侧栏构图。 | 新检验排除了什么解释，仍保留何种替代解释。只画原文支持的模型路径，提出的机制／实验与已观察结果明确区分。 |

有效密度体现为问题、证据与判断之间多了一条可核对的关系。页面字符数、
图片对象数、非白像素和卡片数均不是达标依据。用图像填白区但不增加证据
同样无效；保留必要空白与图表可读性。

## 方法图的最低可执行要求

先从原文写出“输入对象与单位 → 模型／转换及关键参数 → 输出及验证”。
每个环节选择能表达其内容的原生图元：嵌套点阵表达抽样层级，带标签的矩阵
表达变量与样本维度，公式表达尺度变换，分支表达不同估计问题，实测分布或
评价图表达验证。矩形可以承载真实变量与阶段，但不能只装入长段文字。
箭头必须有明确起终点与关系；科学因果边、假说虚线和流程箭头保留不同语义。

示意图注明“结构示意”及不编码的数量；真实数据改绘才按数值编码。
不得因示例提到随机森林就替论文添加随机森林，不把概念树当拟合结果，
不把观测回归经几个箭头变成因果机制。若某步骤的真实模型未知，回到来源
核对或保留待查，不用通用“数据分析”方框遮盖。

## 语言与证据分工

- 页题提出本页的具体判断；20 pt 提示句补充条件、张力或比较基准；
  14 pt 图题命名变量／比较并署作者年；18／16 pt 正文补证据解释与边界。
  同一句结论改写四次不增加信息。长解释、完整推导和来源细节放备注。
- 默认不写“如何解读”“读图指南”“这页告诉我们”“给小白”等教学引导，
  也不写“意义重大”“提供重要启示”等没有对象和条件的总结。
- 按设计选择“观察到／相关”“调整后关联”“模型估计”“因果效应”或
  “据此推测”。协变量调整不自动识别因果。对不同研究的归纳注明比较维度
  与限制；拟议实验与假说不得混入已发表结果。
- 不能只因数值为正就写成某变量引起增长。核对响应方向、单位、估计对象、
  分母、误差区间与营养级／时空尺度；图题也须服从相同证据强度。

## Duffy 方法页的简短对照

弱方案：“文献收集 → 数据分析 → 得出结论”三段文字配箭头，标题与正文
重复“多样性很重要”。读者无法判断统计单位、效应量或不同分析的关系。

可执行方案：Duffy et al. (2017) 方法页以“三个统计问题需要不同的分析路径”
为页题。共同输入端区分论文、研究与估计；用嵌套点阵表现研究内多个估计及
重采样单位，用原文关系式连接丰富度范围与 LRR，用独立的排名图形表达研究内
相对重要性。正文补三条路径处理的独立性、可比量尺与排名边界；示意点阵明确
注明不编码真实数量。次数、计数、公式与路径须核对 Methods、补充材料及相应
图后填写。信息增益是区分三种统计问题，不能把这三条分支套给其它论文。

交付前，依次问：这页解决什么、证据支持到哪里、图中实际编码什么、正文新增
什么、相邻页为何需要这一页。任一项答不清，回到证据或编排修改。
运行既有学术 QA 与 PPTX 文本布局检查并查看实际渲染；自动结果只证明其实际
检查的项目，不能替代科学核对和视觉审阅。

# EasySlides 默认原生学术汇报方法

适用于新建原生可编辑 PPT 且用户未指定其他模板的任务。默认模板 ID 为
`academic_general`，路径为 `templates/layouts/academic_general/`；
机器策略见 `templates/template_policy.json`。用户指定的模板、配色、配图和
内容要求始终优先。现有 PPT 的局部编辑、备注修改、纯预览不重新套模板。

## 入口与材料检查

1. **先问制作路线，等待回答。** 默认提供两项：原生可编辑 PPT；先生图，
   再转为可编辑 PPT。每项说明相对 Token 消耗和耗时，生图用量单独说明。
   推荐项不代表选择。沿用同一任务已经明确的选择，不因后续修改反复询问。
   明确要求图片局部重建时保留该能力，无需让用户改选整页。
2. **原生路线默认本模板。** 用户没有指定模板时直接选用，不额外要求他
   提供模板路径或批准默认模板。图片路线沿用其视觉参考与重建约定，
   不把原生模板强行替换为其来源。图片重建仍需确认全矢量或保留复杂配图。
3. **再确认主题色。** 提供学术深蓝、清华风紫、深绿、科技蓝，支持自定义
   `#RRGGBB`。用户已经指定颜色或明确授权代选时不重问。直接复用现有
   `assets/theme_palette_preview.png` 展示，不为每次问询重新生图或渲染。
4. **选择主题图来源。** 14 个学科门类的已有配图统一称为“主题图”。询问：
   “使用模板主题图（推荐）”，或“单独生成主题图”。前者匹配已有资产并
   裁剪；后者依据本次主题定制无文字图片，会增加生图耗时和用量。推荐项
   不自动选定。已有明确选择或用户提供主题图时不重复问；用户图片优先。
   记录 `theme_image_source` 为 `template_assets`、`generate_new` 或
   `user_provided`。定制的是主题背景，文字和正文继续按已确认路线制作。
5. **检查材料与身份。** 从实际读取的文件和对话提取题目、学科、汇报人、
   汇报人学校／单位、日期，记录来源。论文作者、被引文献作者单位、
   参考模板校徽不代表汇报人身份。只对缺失或冲突项集中补问一次；允许
   用户明确省略。没有提供导师信息也不需要问，模板没有导师字段。
6. **匹配或生成主题图并开工。** 选择已有主题图时，学科优先采用明确门类、
   专业或材料中的主题，使用对应的 14 门类资产。选择单独生成时，先读清
   主题和材料，再用当前可用的生图能力生成一张无文字高清横幅，兼顾约
   3.88:1 的裁剪与中心标题可读性；将原图存项目资产，记录 `theme_image_path`
   并填入封面 `BAND_IMAGE`。不能在尚未生成时偷偷回退到图库。
   跨学科或匹配不明确时补问；
   不把关键词分类称为正式学科认定。学校明确后优先用用户校徽，否则
   调用 ScanSci Logos；学校未知或匹配失败时用中性徽章。

颜色与学科彼此独立。绿色配生物／农学、科技蓝配工程等只是展示示例，
不能覆盖用户选择的学科与图片。封面、目录、章标题裁剪和结尾共享所选
主题图，按各自画幅取景；用户对某页单独指定的图片优先。生成一张后复用，
不逐页重生。若用户选用图库但没有合适资产，说明缺口并询问是否改为定制。

使用 `clarify init --academic` 保存当前学术任务的状态。路线先确定；
原生默认模板随后阻止缺少主题色、主题图选择或 `presentation_identity` 检查记录的任务
直接进入生产。`needs_material_inspection` 是代理读取任务，不向用户弹出
要求其代读文件的问题。记录身份检查的文件页码、用户答复或明确省略，
不能将“缺失”写成“已核实”。完成必要的受众、时长、来源范围和内容边界
后简短复述并开工，不再要求确认已经确认的内容。

将确认后的 `decisions` 原样放入 `deck_plan.json.academic_brief`，并将解析的
`discipline_code`／`research_field`、`presenter_institution`、`presenter`、日期
及来源记录随计划传递；封面和结尾槽位只填已知信息。默认模板选择标为
`project_default`，文件检查标为 `inspection:<file>:<page>`，不得冒充用户回答。

## 内容组织与证据

默认按有专业基础、有学术判断力的听众编排。论文汇报沿“研究背景 →
相关研究／前沿 → 问题与缺口 → 设计／方法 → 结果 → 比较讨论 → 综合判断”
建立论证；这是一条内容路径，不要求各阶段一页或套同一种版式。时长与材料
决定页数。用户明确的提纲、教学要求和保留范围优先。

新原生学术创作在 `deck_plan.json` 声明
`authoring_contract: "academic_native.v1"`。每个正文页先写现有的
`action_title`、`claim`、`evidence_sources`、`speaker_note`，并补齐
`page_brief.question`、`page_brief.information_gain`、
`page_brief.visual_rationale`，再选择版式。问题指出该页解决什么，主张指出
证据实际支持什么，信息增益说明它比前页多建立了哪项比较、机制、限定或
推论；视觉理由说明图形与正文分别承担什么。记录不是另写几句相似的总结。
局部编辑与已有旧计划不追补整套创作字段。

- **先盘点证据，再加密内容。** 每页使用原图、真实数据图、可核对的方法
  结构、关系图或比较表支撑主张；正文补足图中没有表达的条件、比较对象、
  机制或边界。增加互补证据与判断才增加密度，填满字符上限、非白像素、
  添加图片对象或缩小字号均不能证明信息增益。没有合适证据时缩小主张或拆页。
- **按许可范围获取研究图。** 先提取主论文正文、图题、方法、附录与参考
  文献中的可用证据。已获补充调研许可时，沿 Introduction 的相关研究找
  背景／前沿原图，在讨论中比较有实质联系的研究对象、变量、尺度和方法。
  未确定来源范围时记录待确认，不擅自增加外部文献，也不擅自写成
  `supplied_only`。模板主题图承担视觉身份，不能替代正文研究证据。
  PDF 取图按[工具提取方法](scientific-figure-extraction.md)先运行结构化识别，
  保存原图区域、图例、图题和来源元数据；不默认目测坐标裁图，不把纯文本
  解析或嵌入位图枚举当作完整科学图提取。
- **守住证据强度。** 区分观测关联、模型条件下的估计、可识别的因果效应
  与讲者推断。调整协变量不自动建立因果关系。数据改绘保留单位、坐标、
  图例、误差定义和对照关系；不编造数据、统计结果、文献或研究结论。
- **方法必须画出真实操作。** 核对输入、分析对象、模型／变换、输出和
  验证，再用可编辑图形表达抽样层级、变量关系、模型分支、数据变换或
  验证设计。几段文字加箭头不合格。用户随口举的随机森林等示例不构成
  方法证据；示意点阵、矩阵、树或网络须标明语义，不能冒充实测结果。
- **文字各有分工。** 页题建立本页判断；20 pt 提示句补充关键条件或张力；
  图题说明变量／比较与来源；正文补充证据和边界。四处不做同义复述，长
  解释、推导与来源细节进备注。除用户要求教学外，不写“如何解读”
  “读图指南”“这页告诉我们”“给小白”等引导语，结尾不凑空泛总结。

在正文编排前加载 [原生学术逐页编排](academic-native-authoring.md)，按其中
配方选择实际证据的组合方式、检查图文分工；不要把配方变成新的固定填空页。

- **整套版式要有实质变化。** 依据页面内容选择图文并置、通栏主图与注释、
  多图比较、空间结构图、流程／关系示意等不同结构，并调整图、文的相对
  位置、面积和阅读层次。只换颜色、标签、分隔线或花括号，不算版式变化。
  用整套缩略图检查反复出现的相似构图，包括隔页交替和不连续重复；“不连续
  三页相同”只是最低检查，不代表整套已足够多样。保留信息量和模板统一性，
  不为变化而强行加入与内容无关的装饰。

## 文字层级与几何

| 用途 | 字号与格式 |
| --- | --- |
| 章标题／页标题 | 微软雅黑 28 pt，相同字重、顶边、高度和垂直中线 |
| 内容提示句 | 微软雅黑 20 pt，一个文本框，原生实心方形项目符号 20 pt，1.3 倍行距 |
| 正文／正文小标题 | 微软雅黑 18 pt；小标题用字重区分 |
| 次一级说明 | 微软雅黑 16 pt |
| 图题 | 中文楷体、英文 Times New Roman，14 pt |
| 页码 | Cambria 粗体 16 pt，水平和垂直居中 |

正文不靠缩小字号塞入内容；应精简重复、调整编排或合理拆页。封面、目录、
结尾展示标题、独立统计数字、来源元信息和原图内文字各有约定。具体几何
与字号以模板 `layouts.json#text_hierarchy` 为准。

- 16:9 白底，使用 PPT 默认背景；正文不另铺整页纯色图片或矩形。
- 左上章标题不超过 5 个字，取封面资产的有效裁剪，叠加约 75% 不透明的
  深主题色，白字相对矩形水平／垂直居中。页标题与章标题严格共用中线。
- 提示句与页眉保留明确间距，项目符号与文字在同一原生段落中，避免
  独立符号形状、重复文本框或不必要分组造成两个选择外框。
- 各比较列共用宽度、图形边界和文字基线；平行元素等距，连接有明确归属。
  单位数和多位数、短标题和长标题都按固定框居中，不能靠目测移动凑齐。

## 图文版式与图形

- 高密度来自互补信息与清楚的层次，不来自缩字、复述、卡片堆叠或无用备注。
  充分使用正文有效区域，避免右半页或下半页大片空白。图表仍需可读。
- 按内容选择原图主导、多图比较、跨栏技术路线、模型结构、对照表等编排。
  新建 `academic_general` 正文使用已注册的 `scientific_composition`，默认按[阅读任务和证据](scientific-composition.md#choose-by-reading-task)选择组合，复用模板页眉、
  字号和页脚。避免连续三页重复同一种构图；只换构图名称、文字或图片不算
  换结构。不强制每页图片数量、外部研究图、统一卡片或“左图右灰字”。
- 图片直接放上页面，不加背景框、卡片、描边或无意义色块。保留承担实际
  信息的矩阵单元、图形结构及已约定的页眉／封面色带。
- 删去图表周围重复轴标签、图例和结论的大量灰色说明。图题、单位、必要
  限制和出处保留；较长说明放讲者备注。
- 论文图题写成“内容性图名 (Author et al., year)”，如“A对B的影响
  (Tim et al., 2025)”。相关证据用“关系／关联”，不改写为因果。原图号、
  面板号和页码存来源记录与备注；不使用“原论文图 X”作为图题前缀。
- 布局衔接使用主题色原生粗实心箭头，轻微投影，留出文字间距。分支箭头
  用一个闭合轮廓与一次投影，杆宽、头部和落点一致，转角连续，无突出短杆、
  台阶、空隙或叠缝。科学树枝、网络边、原图箭头和假说虚线保留各自语义。

## 封面、目录、结尾与页脚

- 封面为白底＋宽横幅。1280 × 330 区域约 3.88:1，现有学科图按此裁剪，
  图片透明度 30%，另叠加主题色渐变：两端 18% 不透明，中间到 100%，
  保证白色标题清楚。渐变与图片分别可编辑，不能把标题烘焙进图片。
  不保留封面底部多余长横线。
- 目录采用左图右列表，编号自动连续，列表与图片间距至少 40 px；目录
  不显示来源和页码，也不依赖原始参考截图。
- 有主题图时，封面图带与目录图框只保留矩形底、图片和用于标题对比或右缘
  淡出的渐变。封面短柱与目录折线仅在无图时输出。有图版本须在导出前移除
  这些备用对象，避免逐元素回放时短暂出现。
- 封面主标题的单行和双行文本框分别使用 116 px 和 180 px 高度。以可见
  色带的中心为基准居中。提供副标题时两者作为一个整体居中，保留字号和
  相对间距，并在实际 PowerPoint 渲染中检查。
- 结尾沿用封面资产和横幅比例、渐变，结束语居中，下方只放汇报人和日期。
  没有导师字段；缺失的字段和图标一并省略。中性徽章或已核对校徽可替换。
- 文献页脚只在每篇文献第一次正文引用时出现，之后不重复。图题的作者年
  引用仍保留。没有新来源时底部只显示页码，不留页脚横线。
- 页码使用物理页序、不补零、不带总数；默认封面／目录／结尾省略。
  正文右下角 48 × 48 px 的浅主题色正方形紧贴两边，仅左上角圆角 12 px；
  数字在同一固定框内居中。全套遵循一个 `pagination_contract.json`。

并列内容按实际可见元素检查左右留白。数据汇合页以合并箭头为页面中轴，各
输入组的标题、指标和说明沿组内中轴对齐，组内有多个指标时围绕中轴等距
分布。汇合结果的指标与单位按等宽中心排布。原图与正文组合可采用非对称
排版，但须检查视觉重心、外边距和阅读顺序。证据量有差异时，调整分组和
间距，保留有意的留白。

## 制作与交付

复用既有 SVG／shape IR → DrawingML 后端。封面和功能页可用
`semantic_template_renderer.py`，正文按真实材料与版式自由组合；无须强塞
既有的段落槽位。文字、图形、页码保留原生编辑；论文原图作为独立图片。

运行共享 PPTX 文本布局检查，检查实际 PowerPoint 渲染，重点看页眉中线、
20／18／16 pt 层级、原生项目符号、图题、裁剪、页码与箭头接头。几何缺陷
需放大看实际成稿；自动检查通过不等于视觉或科学来源已核实。输入未变的
局部检查可复用；最终实际 PPTX 的各页渲染须由具备图像能力的审阅者检查。
按 [科学正文组合接口](scientific-composition.md#render-and-review) 运行最终
`academic-gate`；图像输入不可用时保持 `needs_visual_review`，不能凭 PNG
导出或像素统计标为通过。交付可编辑 PPT 和少量关键页面预览，
不默认生成庞大 HTML 审阅页、重复配色样张或无关报告。

模板的详细契约位于 `rules.md`、`design_spec.md`、`layouts.json`、
`story_structure.json` 和 `cover_banners/manifest.json`；这份方法文档作为
Skills 的入口摘要，详细约定有变更时同步维护，避免多处矛盾。

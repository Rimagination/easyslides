# 图片参考模板库

此库为图片路线提供视觉参考，与原生可编辑 PPT 模板库独立。
`registry.json` 是图片参考清单；`index.html` 是本地浏览入口。
每个主 PNG 按原始顺序展示一份 PPT 的全部页面，并附原页码。
`*_preview.jpg` 仅用于浏览，生成时优先读取完整 PNG。

## 使用范围

### 存储与加载

- 素材随仓库和插件包保存在 `templates/image_references/`，使用目录内的相对路径，可直接复制到其他机器。
- 先只读 `registry.json` 的 ID、名称、`style_summary` 和 `version`，供用户选择。禁止预加载全部参考图，禁止为模板预先批量 OCR 或矢量化。
- 浏览器图库加载压缩预览图；模型在用户选定后只读取对应完整 PNG。沿用同一任务的明确选择，图片未变时避免重复附图；工具需要重新传入参考时仍正常传入，不承诺缓存免除图像 token。
- 每个模板保留一张完整 PNG、一张预览 JPG、一条索引。风格变化或参考图替换时提升 `version`；只改显示名不提升版本。保持既有配色版本，不合并删除。
- 索引中的 `source_filename` 仅记录来源文件名，无需原始 PPT 即可使用参考图。本机原始路径和缓存信息不随插件公开。
- 单页渲染属于本地缓存。原始 PPT、历史交付及主参考图不作为缓存删除。

- 先按制作方案确认规则询问用户，再让用户选图片参考模板或提供自己的参考图。
- 图片整页重建：参考图片样式 + 用户材料 → imagegen 逐页生成 → 用户预览确认 → 询问重建方式 → 可编辑 PPTX。
- 已有最终页面图片时直接重建，跳过 imagegen；局部重建使用用户确认的页面与批注区域。
- 图片模板只提供配色、版式、背景及图文组织参考。不得把示例的姓名、机构、标志、数据或研究结论当作用户内容。
- 矢量重建与保留复杂配图必须明确询问，两者都使用原生文本框，同一行文字不随意拆框。询问时展示 token 消耗和耗时等级。
- 此库不声明原生文字槽、SVG 布局或 DrawingML 模板能力，不加入 `template_policy.json`、`template_registry.json` 或原生模板选择列表。
- 内置图用于展示与风格参考，示例中的姓名、机构、数据及图示不构成用户的研究材料。
- 来源文件名见 `registry.json`。代码的 MIT 许可不代替第三方模板、标志或图片的素材授权；原始 PPT 与字体文件不随此库分发。
- 用户另行提供的模板默认仅保存在其本地工作区，未经确认不加入公共图库。

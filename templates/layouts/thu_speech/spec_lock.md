# thu_speech stable package lock

This package is the official Tsinghua speech template. The official template policy includes `thu_speech`.

The public contract is five functional shells (`cover`, `toc`, `transition`, `content`, `ending`), one transition series, and fifteen active content variants. Source slide 22 is excluded.

Content images use `contain` with a subtle `#E5DDE8` frame; full-canvas backgrounds remain `stretch`. Native PPTX generation must pass placeholder and round-trip checks before release.

# thu_speech

Stable, source-faithful official THU speech template package.

- Functional shells: cover, toc, transition, content, ending
- Transition: one shared series with number/photo presets for source slides 07–10
- Content: 15 active body variants; source slide 22 is excluded
- Runtime: `compiled/template_ir.json` plus source-template projection for source-faithful variants
- Default template library: `thu_speech` is an official template
